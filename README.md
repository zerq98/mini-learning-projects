# Mini learning projects

A collection of small projects for learning specific technologies through practice.

Each project focuses on one technology. It is as small as possible, yet shows the technology's key capabilities and invites hands-on experimenting. Each one also has its own documentation: how the technology works, explained on that project's code, and which experiments are worth running in it.

These are neither production applications nor elaborate demos. Simplifications are deliberate and described in each project's documentation.
